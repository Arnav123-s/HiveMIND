# The hive's seed

The living state of the hive as it was on 2026-11-11: three bodies, their stem cells, cells, maps and records, the
vocabulary and the harvested text. The hive that grows on GitHub starts from here when it has no grown state of its
own yet (`.github/workflows/hive.yml`), and so can any device:

    python training/hive_state.py pull

This branch has no code and shares no history with `main`.
