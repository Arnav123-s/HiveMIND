# llama.cpp converters (vendored)

From llama.cpp as bundled in llama-cpp-python 0.3.36 (MIT, see LICENSE). Used to turn a specialist's
PEFT weight edit into a GGUF LoRA the llama.cpp engine loads: `training/to_gguf.sh <specialist>`.
`gguf-py/` is the matching gguf package from the same llama.cpp version.
