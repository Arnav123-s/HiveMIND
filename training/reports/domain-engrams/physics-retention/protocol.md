# Independent confirmation of a corrected phase-of-water adapter

The published v1 native check missed one negative-Celsius example. Freeze the corrected teaching choices, algorithm, hyperparameters and adapter weights before releasing these new temperatures and prompts to the trainer or checking any predictions. Nine new English descriptions follow the same existing instruction asking for the equilibrium phase of pure water at one atmosphere. None is at a phase boundary. The six primary descriptions contain two examples per phase, and three supplementary descriptions contain one of each. All nine must be reported in their original groups. The new cases are a purposeful confirmation panel for this particular microtask. They do not test salt water, changing pressure, other substances or general physical reasoning.

Use the native-runner system instruction and original phase-classification prompt exactly as in the first qualification study. For each case, record the actual unrestricted greedy first assistant token with the bare base, original adapter and frozen corrective adapter on the same input and prefix. Accept only the named phase label after the approved whitespace and capitalization normalization. Report primary and supplementary scores separately, individual gains and losses against both controls, and regression results on the three original held-out checks. The agreed release gate requires all six primary, all three supplementary and all three original checks to be correct for the new adapter. One correction run is allowed for this study. Do not retune on any of these nine predictions.
