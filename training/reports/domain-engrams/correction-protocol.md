# Independent corrective candidates

The first physics and computer-engineering edits failed qualification. Their fitted weights and decisions are reproducible from the original study. Each domain gets exactly one additional candidate. Its training set consists of the six original public teaching rows, the three now-released primary checks and 18 new public teaching rows. The extra teaching rows vary temperature signs or equivalent hardware timing units. All earlier scores remain attributed to the first study.

The same t80 GGUF, normal chat template, subject instruction, rank-four output projection and ridge setting are used. For each candidate, the lowercase label and its initial-capital spelling receive the same additive score whenever the spelling is a single native token. The score of a label is its strongest such spelling. On each **training** prompt, the target increase for the correct label is the nonnegative amount needed to exceed every competing vocabulary token by 8 logits. Each rival label gets a negative target of half its positive lead over the expected class, or zero if it had no lead. The existing balanced, regularized fit learns these increments from the model's final hidden state. The output row for every supported spelling of one label shares the fitted factors. The fitting procedure uses no temperature parser, unit table or qualification output.
