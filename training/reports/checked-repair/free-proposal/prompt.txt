Write and save a Python module gauge.py with a function exposure(points, ceiling, max_gap). Points are [minute, reading] pairs in strictly increasing time order. Readings are numbers or None. Between adjacent readings the signal changes linearly. Skip a segment if either reading is None or if its duration exceeds max_gap. Return a two-item list: total minutes strictly above ceiling (fractional minutes count), and the number of eligible segments that start at or below ceiling and end above it. A missing observation or a long gap cannot bridge two segments. Use the standard library.

A previous implementation is below. Return a corrected exposure function in one Python block. The caller will save it.

```python
def exposure(points, ceiling, max_gap):
    if not points:
        return [0.0, 0]

    total_above = 0.0
    eligible_segments = 0

    for i in range(1, len(points)):
        prev_time, prev_reading = points[i - 1]
        curr_time, curr_reading = points[i]

        if prev_reading is None or curr_reading is None:
            continue

        if curr_time - prev_time > max_gap:
            continue

        start_time = prev_time
        start_reading = prev_reading
        end_time = curr_time
        end_reading = curr_reading

        if start_reading <= ceiling and end_reading > ceiling:
            eligible_segments += 1
            duration = end_time - start_time
            if start_reading == end_reading:
                total_above += duration
            else:
                delta = (end_reading - ceiling) / (end_reading - start_reading)
                total_above += delta * duration

    return [total_above, eligible_segments]
```
