# CPU hive calibration experiment

The primary outcome is one successful calibration. The submitted function must predict all eight unobserved settings exactly. A correct fraction of individual settings is a secondary outcome. Each world supplies a function family and hides its signed coefficients. These are small, checkable reasoning tasks.

## Fixed comparison

- Use affine worlds 10 through 15 to develop the interface and teach the child. Use seed 0 for the format pilot. The interaction family supplies no teaching examples.
- Reserve seeds 101, 102, 103 and 104 in both families for evaluation. All arms get the same worlds, eight test settings, six model turns, and four affine or five interaction probes. Test settings lie outside the entire probe grid.
- Compare a single data cell, two cells with assigned roles, and two cells choosing the next worker. Repeat the open setting with the trained child replacing the data cell and the same code peer. Examine peer use as well as correctness.
- Include an open control that routes both roles to the same parent weights under the same prompt. Compare a reusable written method if a cell can derive one from teaching evidence. The holdout stays separate from method selection and gradient updates.
- Separately run a hybrid with the same initial data cell and a human-written exact linear-algebra worker. Only the public probe receipts and advertised function family reach the solver. Compare that arm to fixed corner probes with the same exact solver.
- When a public prediction disagrees with an existing probe, return the first disagreement. Withhold the private grader until the episode closes. A cell can request arithmetic on an expression of its own.
- Account for model calls, generated tokens, elapsed time and peak server memory. Count teaching and testing separately. Exercise recovery in a separate world and switch more distinct adapters than the memory cache can hold.
- Use four additional JSON-scored tasks to check for obvious regressions in the parent and child. They cover a corrected conversation detail, inventory, job ordering and a missing booking field.
- In a separate deterministic stress test on seeds 201 through 204, hide a change from affine to an interaction and then add an unsupported quadratic term. Use the stored procedure plus a fifth confirmation at (2,1). On a disagreement, try the exact interaction worker, then abstain if the public evidence still disagrees.

Four worlds per family can reveal a concrete failure or a working example. They give a coarse estimate of reliability.
