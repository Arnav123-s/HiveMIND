# Frozen practical answer panel

The panel has two independently authored practical questions in each of six domains. Four additional elementary questions test retention in coding, math, physical science and conversation. The 16 prompts and their external answer key were frozen before reading any current domain routing or engram implementation or generating answers. No question, answer, or held-out response may train, name, prioritize or select a memory. Both arms receive the exact same messages in independent empty conversations.

Run the preexisting ordinary chat/work decision path with both HIVE_SIGNALS and HIVE_ENGRAMS disabled, then the new ordinary path with both enabled. Match CPU, DNA, eligible members, inference settings, timeouts and limits on generated work between arms. A model call that runs out of time or a route error is a failed answer. An unconfirmed work result does not count as a correct delivery. Save the user-visible text, any known route, model and engram evidence, and elapsed time. When feasible replay separately with each toggle disabled. Report partial coverage plainly when a run cannot finish. No conditioning an arm on the other arm's outcomes.

Score the direct user-visible answer against the frozen keys. Accept the expected integer or letter as its own first answer, including a short conventional prefix such as “Answer:” or “The answer is”. A letter can precede its option text and an integer can precede the requested unit. Do not award a letter merely because it occurs somewhere in an explanation, or an integer that occurs only in intermediate arithmetic. Keep visibly returned yet unconfirmed work separate. Preserve raw text for ambiguous cases. Report answer scores out of twelve primary and four retention tasks, plus paired gains, losses and ties. Count available evidence of routing to the named domain separately from answer accuracy, and report actual selected memories separately from merely enabling that feature.

This is a small deliberately constructed CPU check of short answers, including closed-choice questions. It does not measure open-ended writing quality, large-project success, broad subject mastery, or training on genuinely new subject matter. If the integrated runtime lacks a learned vector relevant to a domain, count the fallback and disclose it.
