# Confirmation of two-method agreement

An additional English panel was authored by the independent evaluator after seeing the first pair/centroid audit. The new prompts and keys were frozen before running either method on them and before inspecting the serving agreement implementation. The evaluator knows the six domain labels, first-panel failures and the prior-user history rule. No case was selected from model outputs. This is a new fixed panel by the same evaluator, not a reblinded copy of the original panel or an estimate of live traffic frequencies.

There are four requests per domain (one ordinary, one more technically or socially demanding, one referential follow-up and one explicit correction), and six requests that warrant no specialist advice. The six follow-ups deliberately use exactly the same wording across distinct histories. Cases and rationales are kept separate. No parameters may be chosen by these examples.

The sole operational rule is to advise a specialist only if the frozen six-domain request/context receiver and frozen public-data TF–IDF centroid reading the latest user turn each emit the identical non-null domain. Every other outcome is abstention. No confidence escalation, fallback, retraining or alternate rule is selected after the scores. Score exact seven-way decisions, separately count correct and wrong emitted instructions, supported requests withheld, and spurious advice on the six unsupported/ambiguous requests. Distinguish agreement on a named specialist, mutual abstention and disagreements. Quantify correct and wrong advice avoided compared with the learned pair alone. Record conditional accuracy only together with emitted counts. Prefer advising this rule only if it improves issued-advice precision on this panel while keeping at least three quarters of the pair's correct advice. Report false consensus and lost coverage either way.
