## Additional matched-information comparator

Before any learned-router predictions or training phrases were inspected, the evaluator fixed a second conventional classifier using the same public labeled utterances available to the learned sender if the trainer exposes them. It applies word, adjacent-word and within-word character TF–IDF features and cosine similarity to per-class centroids. It calibrates its similarity and margin thresholds on a deterministic, stratified 20% of the public examples by macro-accuracy, then fits centroids to the full public data. Threshold scoring includes a no-advice class when the public corpus has one. This requires no held-out examples and no external model. It appends recent history only when the current message cannot be classified and contains a referring expression. Report this secondary comparator alongside the prespecified lexical and prior-production controls regardless of its score. It is not an extra success gate.
