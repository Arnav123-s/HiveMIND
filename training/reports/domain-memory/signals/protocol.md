# Six-domain advisory routing confirmation

Frozen before the evaluator inspected any training text, learned artifacts or implementation body. The six public domain names and the normal serving interface were known. This authored diagnostic measures domain advice on English requests. It cannot establish improvement in answers from native Hive members, or give a frequency estimate for real users.

There are 60 requests, including eight with each of six domain labels and twelve requiring abstention. A domain is the specialist appropriate for the requested outcome. In this rubric conversation covers interpersonal replies and ordinary social communication. A current local lookup, general factual lookup outside the six domains, or request lacking enough information for a specialist should abstain. An explicit new task overrides an older one. When a terse follow-up has a unique referent in the prior exchange, route it to that specialist.

Known-domain groups include twelve ordinary, twelve difficult, twelve context-dependent, six with irrelevant context and six explicit topic corrections. Each domain has two ordinary and two difficult prompts, two identical-to-other-domains follow-ups grounded in different histories, one noisy repeat and one explicit switch. The twelve abstentions include two of those same follow-ups without history, six outside-domain tasks and four ambiguous instructions. The six noisy repeats and two follow-up strings make parts of the dataset deliberately dependent. Report request-level accuracy and paired results. Do not report 60 independent natural-language samples or use private labels for any model decision.

cases.json contains message/history pairs and IDs. keys.json is held separately and contains the expected answer and a plain-language reason. Runtime inputs use only message and history. Compare identical cases through the normal API, a fixed lexical router built directly from the domain names and general terminology, and the previous production behavior. The previous system had a binary talk/work mode and emitted no six-way advice. Its comparator returns no advice. Include a keyword baseline with and without history. Missing/substituted sender interventions use the learned reader unchanged. Mute the request sender, context sender and both independently. Shuffle request codes across all rows and context codes among rows with history, using fixed seed 171119, a single-cycle derangement and no expected labels. Preserve empty history in its own stratum. If the checked wire protocol rejects missing frames, report the refusal and separately substitute the valid absence code if the interface provides one. No fitting or threshold adjustment after opening the held-out results.

Release gates chosen before scores consist of at least 43/60 exactly correct and no loss to the simple lexical baseline, at least 18/24 combined ordinary+difficult, at least 4/8 per known domain, at least 9/12 context-dependent and 5/6 on each of explicit overrides and irrelevant-history repeats, and at most two spurious specialists on the twelve abstention cases. For evidence that each signal carries information, require at least three more correct context-dependent cases with the true context code than both muted and shuffled context, and at least four more correct direct cases than both muted and shuffled request. Failure of any gate means the panel does not support making this router an authoritative default. A helpful advice-only mode can still be reported.

Primary metrics are seven-way exact route accuracy including abstention, known-domain correct advice out of 48, false advice on 12 abstentions, mistaken advice versus abstentions on supported requests, per-domain coverage, correct/total emitted advice and group results. Compare per-request wins/losses/ties to the keyword and no-advice controls. Record confidence and both original signal codes where available, expose confidently wrong predictions separately and include examples of failures. Separate an improvement in routing from quality of final generated answers. Measure actual CPU-only calls and timing on one machine without assuming speed generalizes.
