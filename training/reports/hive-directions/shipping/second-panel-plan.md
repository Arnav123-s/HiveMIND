# Decision rule for a second shipping reader

The first experimental reader declined every positive and every negative on a separately written 28-message panel. Its input vocabulary and rounding-language requirement were too narrow to make it useful on that panel.

A second reader will accept a direct request for the depot's standard fee without requiring the user to recite a rounding rule. It must still identify the requested action, see complete parcel weights in grams and decline incompatible tariffs and unrelated tasks. The implementer may use the preceding aggregate result and the public contract. They do not receive either evaluation panel. A different author writes the second panel without the previous fixtures, pilot sources or outcomes. Once frozen, everyone can read all inputs to reproduce the results. We will report the outcome even if the second reader fails.

Run the stock saved-method reader, the second experimental reader and an always-decline policy on the same second panel and the same saved shipping program. Count correct completions using exact arguments and fee, wrong-argument calls, calls made on invalid or unrelated requests, and valid jobs missed. A proposed reader is promising on this panel only if it satisfies all three criteria:

1. It completes at least as many valid requests correctly as stock.
2. It completes at least half the valid requests correctly.
3. It makes fewer wrong-argument calls plus calls on invalid or unrelated requests than stock.

These are exploratory criteria for about 30 constructed messages. The human writing the second panel knows the contract. The second panel is the primary comparison for this variant. Passing earns a multi-method test using independently collected requests. Failing means the variant stays an experiment.
