## Verify the grades

From this directory, run `python -m zipfile -e grade-sources.zip /tmp/hive-g48-grades` and then `python recount_g48.py --archives /tmp/hive-g48-grades`. The [source bundle](grade-sources.zip) contains the original 16 grade ZIPs. The script uses Python's standard library. It verifies every original GitHub archive size and SHA-256 hash, both recorded exam revisions, all 64 pairs of seeds, task IDs, kinds, fields and prompt hashes, and every saved aggregate and per-job record. With a GitHub CLI login, `python recount_g48.py --download` fetches fresh archive copies while GitHub retains them. [Source manifest](g48-manifest.json) · [Reproduction code](recount_g48.py)
