# Three matched fresh-only controls

This comparison was specified after seeing that G55 and each of three mixed proposals passed the same three of five frozen requests. Freeze all three replacement rows and this design before fitting or sampling any fresh-only proposal. Run three independent controls from the same original G55 adapter. Use the same two shared examples in the same two optimizer positions, then replace the single old program with a third independently verified G56 teacher example from that proposal's existing kind. Disable replay in the ordinary trainer. Preserve all other fit and inference settings, including the original model name, RNG seeds, optimizer steps, date in the prompts, five questions, raw answer budget, grader and acceptance rule.

Select from the same G56 cumulative corpus. Require an archived first-turn lesson program, an exact regenerated question, an exact regenerated solution and a passing original task check on that solution. Exclude all G55 questions, official reserved kinds, the G56 teacher validation set, all prior pilot practice questions and all five panel questions. Require distinct normalized question text. Sort by absolute difference in target-token count from the displaced old row, then absolute difference in total-token count, then canonical row SHA-256. Take the first qualifying candidate in that order. Record differences in token budget, prompt and program identity and realized optimizer order, without retuning or increasing the number of trials. Reorder only the input file so the ordinary seeded sampler meets the two shared rows in their original order. The third optimizer step is the sole changed training example.

Grade the first program from the five identical prompts in the same WASI environment and compare full functional pass masks and answer program hashes. A hypothetical child is kept only with zero losses and at least one new pass in the three target kinds. Compare each independently to G55 and to its mixed sibling, retaining original adapters. A tied result cannot establish equivalent retention, and the families with a fixed teacher algorithm test new instances of that algorithm. The panel has two old questions and three target questions.
