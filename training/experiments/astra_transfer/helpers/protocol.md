# Frozen selection and evidence rules

Use only SHA-256-verified G50–G52 practice shards. For each question take individually passing workers from its exam record and Python files present in that worker's private result workspace, excluding hidden turn wrappers, shared workspace files, copied prompt inputs, and files supplied by the harness. Prefer graded filenames linked by the worker artifact receipt. Count source files separately from worker and question counts.

Parse top-level synchronous functions without decorators, imports, external globals, nested definitions, reflection, IO or nondeterministic builtins. Admit only a small fixed list of pure builtins and ordinary container/string methods. Require at least one argument and a value return. Normalize argument, function, and local identifiers in the syntax tree while preserving literals, operators, attribute names, and keyword names. Ignore a leading documentation string and type annotations for positional contracts. Reject potentially divergent scope features conservatively. Identical syntax after normalization must occur for at least two distinct whitespace-normalized, case-folded questions. Report how many also span distinct recorded kinds. A worker's passing grade alone establishes no helper contract.

Order eligible signatures by distinct kinds, then distinct questions, then hex digest (ascending for ties). Attempt at most the first one. Before executing it, spell out one narrow typed input/output contract and write independent expected outputs including a boundary or failure. Run only the isolated helper in CPython WASI. Report empty coverage or a failed contract without a substitute. Retain question hashes and artifact provenance without private question text. Ship no live imports.
