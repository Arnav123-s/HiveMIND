# Routing retained specialists after observing failures

Use the previous retention study's incumbent (rank-four head fitted on 18 old examples) and its failure-prioritized six specialist heads, trained on the same 42 disclosed teaching/feedback cases. Preserve every head byte-for-byte across all rounds. The old study's oracle-supplied domain assignment finished 38/48 and the incumbent also finished 38/48, with five gains and five losses. No official release-exam examples enter this experiment.

For every request compute the actual greedy normalized word for the incumbent and every stored head, including the strongest outside-vocabulary token. Project heads over the same cached native hidden state. The candidate selector can return only one of these observed answers. The task instruction supplies three allowed output words; its declared domain comes from this instruction. No independent verifier for the content is available during the decision.

Freeze the following alternatives before examining new per-case outcomes. The primary gate keeps an incumbent whose word fits the requested vocabulary, unless an earlier feedback ledger supports switching. Whenever the incumbent emits an invalid word, choose the nearest externally labeled example's word if a head emitted it, otherwise the first in-scope specialist's eligible word, otherwise the next eligible archived word in stable order. When the incumbent emits a legal word, propose the word of the nearest labeled example in this domain if an archived head emitted that word. Credit the proposal only **after** collecting the external label. A switch may be used on later requests when at least two previous disagreements with this same domain and incumbent word favored the nearest-neighbor alternative and none favored the incumbent. Log ties and all rejected switches. The teaching examples initialize nearest-neighbor prototypes but **no** route-support counters. Semantic distance is cosine on native hidden states centered with the fixed per-domain teaching mean. Fixed relative order breaks ties.

Controls: incumbent, queried domain's newest head, batchwise strongest single evaluated on prior feedback only, fixed-seed random eligible expert, the same gate with a permanently empty ledger, the nearest-label candidate selector without the evidence gate, direct nearest-label classifier, the base model's largest logit among the three canonical allowed token IDs, and per-row hindsight ceiling among actual archive outputs. The last two direct comparators may construct a choice unavailable to the archive. Fall back to the incumbent if no valid candidate exists. Keep abstention and any new errors explicit. A guarantee that an invalid starting word was already wrong is confined to correctly specified closed-vocabulary requests.

Order the 48 disjoint prior published withheld prompts by a fixed SHA-256 salt across domains, in four waves of 12. Freeze all answers in a wave before disclosing any labels from it. Previously disclosed examples enter memory and feedback only for future waves. After each release score the current router also on all previously seen waves for paired retained successes/lost successes (without storing an exact-case override). For a separate genuinely fresh terminal confirmation run new native 8B states/logits supplied by another author after the policy freeze. Keep this whole confirmation set sealed as one batch. Report per-policy numerators/denominators, overlap and oracle gaps, actual prediction arms and case IDs. The archival and terminal panels test within six existing decision contracts. They cannot establish monotonic generalization across generations or a score on five of the ten release kinds.
