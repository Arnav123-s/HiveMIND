Retain ordinary standard imports, literal module constants, and complete worker definitions. Remove worker drivers. Test the examples in a WASI guest, and publish only when the qualified candidates agree on the outputs requested in the final instruction. Preserve the original outcome when the route cannot check the request. This is a general file-packaging proposal. It cannot supply a missing algorithm or prove a program from a finite set of examples.
