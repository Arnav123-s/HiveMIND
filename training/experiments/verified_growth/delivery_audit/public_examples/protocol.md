# Grade-blind evaluation of archived user examples

Use every locally available G50–G52 gate archive in the fixed manifest whose SHA-256 matches. Include every members/TASK.md beginning “Write a Python module”. Each before/after body is a distinct attempt on the same prompt. Index module families by requested filename. Extract original user text, visible report, all attempts in worker/turn order and their source identities. An absent archived report is missing evidence and cannot be replaced with an empty prior delivery. Preserve each existing non-declined delivery. The archived work-file allowlist excludes requested modules, so infer an unresolved delivery only from an explicit decline and never overwrite a success.

Apply the byte-frozen file_relay unchanged to the original prompts, reports and submitted programs. Inventory parser coverage over all attempts. For an execution-only diagnostic on every duration attempt, transcribe the user's literal calls before and after “Then tell me” with exact adjacent expected literals; remove no punctuation from or send a rewritten prompt to the relay. Run all distinct modules extractable by the frozen declaration filter in the WASI guest. Record each visible check and query output, without using historical stdout as an expected answer. This diagnostic is not a shipping rule. Its generation-52 after-body cases had previously been investigated.

Controls construct example-only functions mechanically from every public input/output pair, returning a zero value of the first displayed output type for any other input. Through the unmodified proposer try both a lookup singleton and, where worker sources exist, lookup plus the real sources. Test the unfabricated stock.py prompt already in the relay's controls as a positive parsing control. A lookup example pass has no value as evidence for generalization.

As a second, separately frozen parser study, after the independent developer supplies source and digest, run the same proposer changing only its contract parser for this evaluation. Freeze all comparisons against stock before reviewing private verdicts. Count all 90 attempts including missing reports, grouping known G52 duration failures, other attempts on the same prompts, older duration attempts and all other module families. For the alternative, run every declined supported real job and both lookup controls on the same declined prompts, up to the first 20 eligible jobs in manifest order (excess would remain reported as covered but unexecuted). Never replay a private grader in the decision subprocess. After writing and hashing decisions, grade files and reports separately. Hash archive inputs, modules, prompts and the source of each parser. Log guest calls, integer fuel, measured time, number of input rows, wall time and execution CPU. A measured run may share CPU resources with other ongoing work.
