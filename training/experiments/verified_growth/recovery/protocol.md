# Interrupted training slice

Freeze a 32-update CPU training slice with four rows per AdamW update and a five-update checkpoint interval. Use the existing 60 training rows of the archived T80 endpoint dataset, its six domains and real first-token features/logits. Train a rank-four output correction with the repository's TernaryLinear, Study picker, gradient clipping and lr_share schedule; use dropout 0.1 to exercise stochastic restoration. Run three matched trajectories: uninterrupted, abrupt exit during row 95 plus a restart from scratch, and the same abrupt exit plus a fresh process that can read only independently retained checkpoints and immutable inputs. Compare model parameters, AdamW moments and step, Study state and private RNG, Torch RNG, next Python RNG draw and the complete loss/row sequence. Compare successful update count and total rows actually executed. Attempt corruption and wrong-input restoration separately. This tests recovery of a fixed-work CPU slice, not live 8B wall-clock saving.
