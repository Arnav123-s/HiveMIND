# Public GET cache experiment

Compare the same real HTTP requests against a loopback server with a new reader for each arm. Count requests at the server and check the exact returned data. Reuse the five-page, one-URL cursor fixture from the adjacent web study, first unchanged and then with explicit public freshness. A second traversal of the cacheable variant must avoid redundant origin requests and produce the original author counts on both traversals. The first traversal still requires five origin fetches.

Additional controls cover expiration, request and response restrictions, encoding, redirects, partial responses, bounds and new run isolation. No external traffic, production monkeypatch, model call, or inferred effect on hosted scores.
