# Native three-factor composition trial

The service code has three binary properties. A human supplies the mapping from properties to letters and the same instruction to every arm. Eighteen examples cover six of eight combinations. The decoder sees new wording and new numbers on all eighteen evaluation prompts. Six prompts use two combinations absent in training. Twelve retain the familiar combinations. A direct implementation of the supplied rule is the exact reference for this finite problem.

Before inference we fixed a bare CPU model, a single rank-four head trained on complete labels, each of three rank-four factor heads alone, three heads at scale one third each, and three heads at scale one each. All arms use the same frozen 8B base, same examples, and unrestricted greedy first-token generation. Single heads are controls for the complete code. Measure exact delivered token on each slice, retain every arm, and do not select a scaling factor from these results. The structured heads receive the codebook’s factor-to-token mapping, including the unseen letters. The joint fit receives only its observed training labels. All arms see the textual codebook. The rule itself requires no language model. This tests conditional label composition, not general neural input parsers, mathematical kernels, free-text renderers, or a full generation gate.
