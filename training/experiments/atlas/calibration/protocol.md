# Prospective analysis of archived agreement

Freeze these methods before inspecting the per-seat outcome archive or any earlier pulse-study performance table. The official aggregate G52 scores and the archive design were already public to the analyst. G50 supplies a development/identity-history split (27 jobs, eight seeds). G51 alone supplies calibration (27 jobs, eight seeds). G52 is the final test (28 jobs, eight seeds). Use every archived complete four-output panel from the published stdout cohort, including empty strings. Each panel contains after seat 1, after seat 2, before seat 1, before seat 2. Check for exact prompt overlap across splits and report a no-prior-prompt sensitivity. Do not reweight according to observed test outcomes. These are historical candidate pools with distinct model weights and task samples.

Group submitted text with the existing pulse.policy.key. Choose the first submitted representative of the most frequent nonempty group, with ties resolved by recorded seat order. If all are empty, there is no proposal, its binary correctness is false, and it cannot be delivered. Only the external recorded verdict of the actual representative can score it. At deployment the decision function has no verdict access. Let m be the winning group's count less the runner-up count, using zero when absent. For a submitted proposal let p=(1+m/4)/2; set p=0 for a missing proposal. This heuristic score measures agreement and carries no assumed probability calibration.

1. Compare first-seat, always-release plurality, two-seat corroboration, the ordinary three-seat consensus, the published four-seat agreement and reserve, and the archived actual after arm. Charge all four seats when a policy reads all four to derive scores. The archived actual arm has its own concurrent-member semantics. Separately show the nondeployable ceiling if any of the four original outputs was correct.
2. Primary split conformal uses the binary truth of the pre-specified plurality proposal. Nonconformity A(x,correct)=1-p, A(x,wrong)=p. Calibration quantile is the ceil((n+1)*0.90)-th smallest realised score with an appended infinity. At test time include each of {correct,wrong} whose score is <=q. Release a nonempty proposal only for singleton {correct}; withhold for both, neither, or singleton {wrong}. Report set coverage for the binary event, set sizes, released/total, correct/wrong deliveries, wrong per accepted, wrong per task and seats. This constructs no open-world text prediction set. The selected proposal was fixed without examining labels.
3. Repeat split conformal by taking each G51 seed's maximum task nonconformity, targeting simultaneous accuracy across tasks in a new seed. Keep 90% target fixed. If eight calibration seeds cannot support that quantile, report the resulting trivial sets. State exchangeability assumptions for any hypothetical guarantee, especially lineage shifts, paired workers and seed correlation. State the unconstrained worst-case risk on an unfamiliar distribution.
4. Separately test the selective-risk target P(wrong|release)<=0.10 via a fixed grid of release thresholds m>=0,1,2,3,4. Compute one-sided 95% exact Clopper–Pearson upper bounds on G51 retained jobs, with Bonferroni adjustment for five tried thresholds. Choose the lowest passing threshold, or abstain everywhere if none qualifies. Show raw G52 risk/coverage and per-threshold descriptive bounds; use exact two-sided 95% binomial intervals only as iid sensitivity, not as a guarantee for correlated records. Report observed wrong unanimities and prompt/seed overlap. A method can meet marginal coverage while accepting no requests.
5. For an archive control, index G50+G51 individual correctness by registered kind and exact worker identity, ignoring any earlier identical prompt for that particular target. Among present G52 workers with at least two eligible training trials in that kind, route to the highest smoothed historical fraction (hits+1)/(n+2); tie in listed seat order. Otherwise use the after trunk, and count all fallbacks. Charge one seat and compare directly with always-after-trunk and always-before-trunk, on the same G52 requests. This tests historical specialist retention and cannot speak for unavailable extinct workers. A MAP-Elites optimization algorithm was not run.
6. For a Hedge comparison, treat the four before/after seating roles as experts. Start equal before G50, multiply each role's weight by exp(-eta*mistakes) on G50 and G51, with eta=sqrt(2*log(4)/54). Freeze weights before G52; choose max weighted nonempty answer class (ties first seen). It probes a learned voting rule over roles whose physical models change; do not claim an online-regret bound for final exact-match system performance.

Only compare outputs on the exact same within-generation job. Do not combine headline fixed exams, differently seeded full exams or pre-existing published held-out grades as extra calibration samples. Publish all selection indices, counts, recorded-grade provenance, confidence bounds and alternate honest failures. No WASI, GPU, LLM or new training.
