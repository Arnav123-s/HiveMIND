# Confirm a first worker before requesting another

Use the complete after-body fresh pulse from generation 49, all eight shards, with their original task ordering, worker outputs and actual delivered reports. This generation was excluded from the G50–52 pulse experiment. No G49 artifact for this study was inspected before fixing the policy. Do not train or adjust any pattern from these results. Report all 64 tasks, every certified case, every fallback, incorrect deliveries, withheld deliveries, completed seat counts and reconstructed saved seat intervals. Count explicit misses as well as correct certifications. Hash inputs for exact deduplication against the earlier G50–52 public panels, and separately report the truly new subset.

The proposed policy may return the *original first worker's whole text unchanged* for a single fully recognized Gregorian weekday, elapsed days, greatest common divisor, percentage price change, or temperature conversion only if that whole response equals an independent computation in meaning, requested units and precision. Recognize explicit complete prompt and answer shapes only. For dates reuse the existing writer calendar parser under a stricter full-date grammar; arithmetic uses exact decimal or integer operations. The selector must not read a maker, seed, exam checker, verdict, other seat or official output. An absent or failing certificate falls back to the recorded normal after-body delivery without any changes. Validate wrong units, wrong answers, extra claims, extra instructions, ambiguous dates and rounding. The existing exam checker runs only after selection. This is a retrospective counterfactual on genuine workers; no inference savings were measured live.
