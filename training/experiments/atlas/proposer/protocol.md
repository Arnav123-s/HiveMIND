# Six independently scored work orders from four typed operations

An order has a case-sensitive site and target label plus rows with site, label and signed integer quantity. Enumerate all one-, two- and three-step sequences of distinct compatible operations starting at the rows. The four operation signatures are filter site (rows → rows), count target label (rows → integer), sum quantity by observed label (rows → totals), and choose highest total, lexical label ascending on ties (totals → label; empty result null). Keep programs returning a scalar or totals. Render a readable task and execute the exact same AST. Before any grade keys are available, freeze these operators, enumeration and comparator. There is no language model, learned solver or access to independent expected values during generation.

Measure correctness per configuration over all scenarios written and keyed by an independent evaluator. Evaluate one operator maximum, same-output-type single-primitive fallback (e.g. unrestricted count for site count), full typed composition, and a conventional hand-written interpreter that can do all six jobs. Charge all six configurations as requests in every arm. Separately count unique ASTs, unit signatures, witnessed changes in answers due to composition, wrong/unsupported returns and correctness on unseen inputs. The scope is bounded to these four known capabilities; success generating an assignment does not establish discovery of a useful new operation or a solver for arbitrary prose.
