# Native verification steering pilot

Freeze six human-authored contrastive pairs about checking versus accepting a claim before answering. The pairs contain no answers to the eight test statements. Use the pinned CPU control-vector generator's mean-difference method to produce one compatible T80 GGUF. Compare the same bare model, an explicit reminder to double-check, and the control vector at positive and negative strength one on layers 20–30 inclusive. Use separate graph-safe native launches for vector arms to avoid stale adapter state. Every test receives the same fixed seed, one-token greedy budget and a binary judgment; correctness is balanced. Measure exact first token on all eight alongside latency. The negative direction serves as a sign control. No selection or scale tuning follows the test.

This tests a contrast of verification language. It cannot guarantee that a model executed an independent verification. The mean-difference implementation from the pinned runtime pools layer activations and differs from methods using only a final-position contrast. Added vectors require generation, storage and per-layer arithmetic even if they save a second model call.
