# Guarded kilogram trace

This opt-in experiment asks whether repeated successful use of a checked program can remove a verification step on a new input form. The parent is the released G47 depot shipping program. The new grammar accepts one to sixteen explicit decimal kilogram quantities in the sentence `Calculate the depot shipping fee for 0.255 kg and 1.75 kg`, with an optional `using per-parcel rounding` or `using pooled rounding`. Each parcel must convert to a positive whole number of grams, at most a million grams. All matching is over the complete stripped request. [Parent bank](../../../reports/retained-skills/shipping/bank/)

The stock arm calls `team.saved.answer` with the actual configured bank and CPython WASI. The handwritten arm gives the stock dispatcher the same fully parsed request in whole grams. This is the direct alternative a developer might reasonably ship. The guarded arm starts with the same conversion. It records up to three successful fallback executions on numerically distinct shipments for the same parent and rounding mode. After that threshold an independent caller must provide at least four other distinct shipments with known fees. Every expected fee must match the compiled candidate in WASI. Calling `qualify` on the three exits themselves cannot publish a sibling.

The candidate combines an authored, exact decimal conversion with the actual parent's source. All prices still come from executing that code. The experiment supplies the grammar and compiler. It measures representation reuse and whether verified specialization saves real execution work. There is no model-based discovery in this experiment. For an explicit rounding convention the saved dispatcher ordinarily rechecks diagnostic bills on each request. A qualified sibling can execute its already-bound program once. A healthy untreated request still goes through the stock dispatcher. When several parent versions exist, the guarded arm always uses the original agreement and convention checks. A competing contract, altered parent record, invalid shipment or unsupported wording cannot reuse the previously admitted branch.
