# Frozen decision experiment

Before scoring, fix three policies, a same-roster order control, executable checks and budgets. This experiment begins after worker responses have been generated and asks which answer would have reached a user.

* Current calls the real solo agreement and winner functions after two then at most three proposals. Use tuned coder, stock sibling, then fast coder. This represents the decision rule given these seats. Production roster selection depends on installation and history.
* Forced diversity substitutes a Yi coder at the second seat and then uses the fast coder. The order control uses tuned, fast, then stock, keeping the original three checkpoints.
* Verified dissent requests the same first two as current. A fixed full-match language grammar may bind one arithmetic or ASCII operation. Check the proposed answers against its exact trusted reference in WASI. An independently checked singleton may win. A failed check cannot confer agreement. Ask the third only if necessary. At most two WASI calls and three distinct proposals per request. Without a binding use the current decision. Return an actual submitted candidate or abstain. A direct solver would need no member on the recognized tasks.
* Archive scoring uses all 32 paired school prompts and the existing teacher keys, previously public. Do not treat teacher keys as universal ground truth. Show correct, wrong, abstained, seats and verification cost. No model is run. Independently authored unseen prompts with constructed per-seat replies test decision behavior and scope separately.
* Program-level witnesses use all eight real peer-study programs in the three archived correction chains. Construct three in-domain proposals per contract before grading. For each positive-multiple task of period k use k−1, k, k+1. For transit use the empty schedule, two equal times, and the half-open endpoint [0,50]. Reject a negative input for every contract. Verify claims by running the original program under WASI and independently deriving the expected answer from the contract. Reject an allegation if execution agrees. Compare incumbent, first peer, and first survivor after checking incumbents and peers in order. Never generate a replacement. Run a separate fresh-input replay of all attempts to check whether selection generalizes. Some chains have only two observed attempts. The historical peers saw public feedback, so these are dependent repairs.
* No thresholds, roster, grammar or witness selection may be tuned on the independent panel. Publish wrong and missing deliveries. Replay time excludes model inference since responses are archived.
