# Exploratory replay protocol

Freeze before evaluating the arms. Use only the 90 archived real t80 final states and native logits reproduced by the sibling island study. No native generation, clocked multi-turn learning or new evaluation labels.

1. Hold back the lexicographically smallest SHA-256 of the original *teaching question* for each domain and label (18 newly reserved for this follow-on). Earlier studies trained on these published prompts. Keep the previous 18 anchors and 12 additional water/timing holdouts unchanged. None of these 48 examples may enter any prefit, feedback, fit or selection. The remaining 18 original teaching cases train a broad rank-four incumbent. The remaining 24 supplemental timing and water rows are the only new learning feedback. The original, already learned 18 are the entire rehearsal bank.
2. Every arm inspects the identical 42 earlier/current labeled cases once with the same prefit incumbent. Split 12 fitting exposures evenly over the six fresh domain × label strata: balanced selects by SHA-256 of the question; priority first selects real incorrect native argmaxes, then sorts by (strongest competing native token minus canonical correct-token score), then frozen hash. No-anchor arms allocate all 12 to current cases. Anchor arms allocate six to current cases and six to older, incumbent-correct cases, round-robin across domains, with SHA order ties. These rehearsal rows have zero incremental target (preserve the old scores). No duplicated exposure.
3. Each wrong selected current case raises its correct canonical-token score to six above the strongest competitor; other increments and already correct examples' increments are zero. Fit the residual in sample space with the same normalized ridge 0.1 and effective QR/SVD rank four as the island experiment. Compare one broad head using all selected exposures to six forced domain heads (each starts from the same prefit; each selects only its domain's share of the same 12). Forced routing receives the correct domain and stores up to six heads. Test zero-shot from the fitted weights with no rehearsal-bank access. Keep the bare and prefit models as no-learning controls. Measure selected failures repaired/regressions on selected known-correct cases separately from 48 excluded cases, per split gains/losses versus the incumbent, actual training CPU and stored coefficients.
4. For a separate two-slot routing miniature freeze the balanced-plus-anchors broad and forced specialist policies above before reading results. Each of 48 unique held-out inputs is served by its specialist if that domain was resident beforehand, or by the broad head otherwise. All policies receive the same two offline post-response checks (actual broad and designated expert token); label feedback may update future decisions only. Two fixed streams, hash-ordered interleaving and contiguous alphabetical domain blocks with hash ordering within a block. Fixed resident domains are the alphabetic first two; LRU retains two most recently used; success-weighted edges decay by 0.9 each round, add +1 when only the specialist succeeds and -1 when only the broad succeeds, and retain up to two strictly positive edges with deterministic ties. Start adaptive policies empty. Count hits, switches, unique correct answers and changed outcomes versus the broad head. Score the possible per-row oracle ceiling separately. This tests a tiny feedback routing table with true domain identities; it cannot show a physically grown network or superior real traffic.
5. Train each fitting arm seven times after one warm-up, rotating order, one thread. Report median selection-plus-fit process time plus per-arm selection decisions and counts, without charging cached 8B extraction. No parameter choice/selection based on excluded cases. The measurements cannot estimate action turns, stochastic resonance, real generative discovery or inherited capacity to learn.
