# Independent prospective confirmation

Two panels were sealed before inspecting the new implementation, development fixtures or outcomes. The questions, candidate answers, oracle and threshold were set from the public behavior description alone. The small bank credential is intentionally public. Only that packet and separate warm-up requests may initialize the trace. Never add a confirmation row to a credential or change a policy after reading its score. On the non-symmetric mixed bank, use the submitted existing per-parcel implementation and an independently admitted pooled version. Each arm begins with fresh state.

Shipping has 32 English requests. Replay all of them in original order on the single and mixed banks with the shipping adapter disabled, a direct handwritten adapter, and the calibrated guarded implementation. For the guarded arm preserve cold-side results and separately report qualified warm results, first qualifying calls, state/method calls or WASI guest invocations when available. Compare selected fee against independent Decimal ceiling arithmetic. Count correct fee delivered, wrong fee delivered, expected amount withheld, and justified abstention; distinguish None/unsupported, ambiguity and unavailable conventions when possible. A return containing a numeric amount in prose is not automatically a method answer. Qualification, calibration and confirmation are disjoint. The full panel still counts if a policy never qualifies. Honest failure of a predeclared grammar or missing legacy fixture is retained.

Dissent has 26 new natural-language tasks paired with a controlled set of four proposed worker outputs. This tests the end-to-end decision component, including the real bounded oracle if invoked. It does not assess a language model's chance of proposing an answer. Run 'current', 'diverse' and 'verified' once with fixed member identifiers and fixed candidates from the panel, in fresh state. Use the actual runner on CPU with no model generations. Count exact correct deliveries, wrong deliveries of a value, no delivery for answerable items, and unjustified deliveries on underspecified/out-of-scope multi-part items separately. For wrong or ambiguous cases, distinguish a verifier's own checked release from agreement fallback. Record individual seats, independent checks, and wall time; report the distribution by normal scope, semantic shift and outside scope. Text equality strips outer whitespace and ignores case for yes/no only. Report controlled data and real archive data separately. Small curated panels, unsupported English and equivalent-but-differently-formatted text limit generalization. No broad claim from this study.

A practical hurdle for the guarded path is improving correctly delivered fees over the original while producing zero wrong releases and preserving the legacy control; compare its cost separately against the handwritten numeric adapter. For dissent, preregister a strict deployment hurdle of zero false checked releases, zero increased wrong or unjustified overall deliveries versus current on the full panel, and more correct answers than current. Unchanged or poorer outcomes must be retained. Resource accounting includes checks and opened seats.
