# Registered frozen-feature comparison

Six islands, one per decision domain, update a rank-four output projection on actual 4,096-component last hidden states from Ternary-Bonsai-8B. Register these choices before comparing arms. Nothing here runs autoregressive generation or trains the 8B base.

* Train on the 36 original teaching cases and four of the six additional teaching cases per label in each of the previously published water and timing extensions (60 total). For these extensions, hold out the first two per label by ascending SHA-256 of the exact question. All 18 original primary checks remain anchors. The 12 additional held-out prompts cover only water and timing. None of the 30 labels used for scoring enter the fit or selection. These are old public datasets, not a newly blinded sample.
* Compare all 60 training examples to a deterministic, class-balanced half. Within each domain and label retain the half with largest base error margin (best competing token minus correct canonical token); break ties by example ID. The three fixed rounds interleave selected and unselected examples equally, with every training row used exactly once in the full arm. This estimates the combined cost and effect of the budget and this particular selection method.
* Cross each dataset budget with elastic pull 0.5 (growth default) and 0.1 for three rounds. Begin at zero. Each island starts a round from its previous local head pulled toward the previous six-island mean. Fit a residual update on that round's rows, on the three canonical output tokens for that island. The target is a six-logit margin for the correct token relative to the strongest unedited competitor (zero increments on the other domain labels). Use sample-space ridge 0.1 with each feature vector unit-normalized for fitting, rescaled by the round's median original norm when mapping back to raw states. Use real QR/SVD merge from training/merge.py for truncation. Islanders and compressed trunk have rank four. After round three, apply the same half-pull migration once to every arm; no additional gradient/fit.
* Score the frozen base, global trunk and the correct island (supplied domain) each round and after migration. Determine the unrestricted argmax using all 18 changeable token logits and the native best unchanged token out of 151,669; accept exact label after case-folding and stripping token whitespace. Also report exact canonical-token matches and per-example results. Earlier-anchor retention is measured on the same 18 untouched anchor rows each round. Full/all-rows + 0.5 is the factorial control. A pooled all-60 fit is an extra centralized, single-fit comparison.
* Diagnose final merging with the true squared singular values of the exact mean projection, rank 1/4/8/16/32 cuts, and sign-flip control (alternate +/- whole island effective weights in alphabetical domain order before averaging). Measure pairwise signed Frobenius cosines of the trained weight matrices, negative pairs, cancellation and ordinary-vs-signed prediction differences. Equal-sign, rank-32 controls must numerically recover the dense mean. No rank chosen using evaluation.
* Run each arm in a fixed rotated order for nine one-thread cycles after a warm-up. Report median CPU seconds including fit, selection charged to the half arm, and merges; separately time fitting and the data selector. Exclude data import, feature extraction, held-out evaluation and native decoding. Empirical timing claims apply only to this program and machine.

The round assignment is independent of difficulty. Each island gets one of its three answer classes per round in canonical-token order, rotated by its alphabetical domain index. Earlier-class retention is therefore a deliberate stressor. The local target's positive increment is max(0, strongest competitor − gold + 6). The previous local/trunk mix is retained outside the three updated rows and subsequently truncated. The pooled upper-cost comparison fits all 18 output rows in one step and truncates to the same rank four.
