# Can consistency relations select a correct durations module?
 
Use both archived G52 durations.py files. Include two explicitly human-written negative controls, one that models elapsed hours as a time of day and one with 61 seconds to a minute and 61 minutes to an hour. All candidates use the same fixed inputs and CPython WASI sandbox. Test three relations without private answer keys. (1) Parsing a formatted nonnegative integer returns the original. (2) Formatting parsed canonical text returns the original. (3) Parsing ordered fragments containing distinct units produces the sum of the parts. Fail exceptions and nonconforming return types. Admit every candidate that passes all relations. If choosing a single candidate is required, pick the lexically smallest full SHA-256 of the surviving source. Report real-only and all-candidate outcomes separately. Write the candidate digests, test inputs, every output and the decision before importing any 60-case holdout data. Grade every candidate after selection with the unchanged pre-existing 60-case duration exam, SHA-256 a80490174d28b72b7b453553c6680a7c8d8fe2458e54d881e68659a01f58db2e. Candidate operations execute exclusively in WASI. The experiment author also wrote the earlier panel, and fixed these relations under that disclosure. The correct hours/minutes/seconds ratios are deliberately absent from the three relations, so an internally consistent nonstandard clock is a falsification control.
