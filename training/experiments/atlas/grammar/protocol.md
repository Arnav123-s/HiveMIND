# Paired constrained generation on the pinned CPU model

Measure whether grammar-constrained sampling improves the machine-readability and the correctness of short answers. The eight actual user questions, their permissible output schemas, and their independently authored answer keys are frozen before any request is scored. Both arms receive the same system message, user question and rendered native chat prompt. Both use greedy sampling, seed 1709 and a 32-token completion cap. Use one isolated two-thread Ternary-Bonsai-8B CPU server with no adapters, no server-side prompt caching, and alternating arm order across successive questions. The generator reads the schema and question only. It never reads the keys or scores.

The constrained arm adds the GBNF `grammar` field to the native `/completion` request. The identical free arm omits it. An integer permits different signed values, an integer array permits differing lengths including zero, and an enumerated field must have at least two possible values. JSON objects use the requested fields in their declared order, with optional spaces around separators. The grammar therefore supplies output structure and the specified answer vocabulary. External arithmetic, factual lookups and model fine-tuning are outside the protocol. A separate forced-literal control checks that native sampling actually changes when a grammar excludes the model's preferred answer. This control is excluded from all eight-task scores.

Report the independent grade for exact output form and for identifiable answer content, each out of eight, plus the joint total. Expose every raw reply and disagreement, including the insufficient-evidence item. Count generated tokens and native process CPU seconds per arm, and report wall time descriptively. A cap that truncates a candidate can still yield an incomplete expression. A syntactically valid but substantively wrong answer earns format credit only. A user request whose uncertainty is semantically valid needs an admissible abstention. Outcomes on this small, heterogeneous panel establish effects on these questions only.
